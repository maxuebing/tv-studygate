# 硬件适配笔记（小米电视 / 国产 Android TV 固件特性）

以下为在小米电视 A55 竞技版（MiTV-ASTP0，Android 9，armeabi-v7a）真机验证的行为记录，
同类国产 Android TV 固件大概率类似。TVStudyGate 的保活设计基于这些特性。

## 固件特性

| 特性 | 行为 | 设计应对 |
|---|---|---|
| ADB 开关 | **断电/开关机后自动重置为关闭** | ADB 仅用于安装/升级；运行期完全不依赖 ADB 通道 |
| 应用 stopped 状态 | 电视管家可能把应用置为 `stopped=true`，收不到开机广播 | 无障碍服务由系统开机直接绑定（绕过广播）+ JobScheduler 跨重启周期保活 |
| 无障碍配置 | 写入 `secure` 表后断电**保留** | 锁屏防逃逸与开机拉起的主要通道 |
| appops 权限 | `SYSTEM_ALERT_WINDOW`/`RUN_IN_BACKGROUND` 等 ADB 写入后断电**保留** | 安装时一次性写入 |
| 悬浮窗层级 | `TYPE_APPLICATION_OVERLAY` 可覆盖桌面与第三方 App | 全屏遮罩 + 失焦时 remove/add 重新置顶 |
| 语音助手 | 语音键可呼出系统弹窗抢焦点 | 锁定期每秒检查窗口焦点，失焦即重置顶 + 关闭系统弹窗广播 |

## 架构红线

1. 计时/锁定/断电记忆必须驻留电视本地（`SharedPreferences.commit()` 同步落盘），
   严禁设计依赖常驻 ADB 通道的方案；
2. 「无障碍服务开机拉起 + JobScheduler 保活」双链路不可移除；
3. 锁屏交互只做四选一，题干不依赖图片/音频/表格。

## 已知边界

- 不阻止卸载 App、不阻止使用其他设备看视频；
- 恢复出厂设置会清空全部权限与落盘状态，需重新安装授权；
- 视频暂停为尽力而为的系统级音频焦点请求；
- 语音助手弹窗弹出瞬间可能短暂盖住锁屏，约 1 秒内被自动压回。
