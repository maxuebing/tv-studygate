# TVStudyGate · 答题解锁看电视

**Android TV 电视防沉迷锁屏系统 + 家庭题库服务器**

到点锁屏 → 答对单元题 → 继续观看。断电重启不重置进度，家长手机远程放行。

## 它解决什么问题

孩子看电视时间失控、遥控器一关一开就"重置"了家长的规定？TVStudyGate 把**答题**变成看电视的闸门：

- **每 10 分钟锁屏**：电视弹出全屏答题遮罩（盖住任意 App / HDMI 输入），四选一答对才继续看；
- **做错加题**：答错 1 题剩余需答对题数 +1（封顶可配），并强制停留 8 秒阅读错题解析；
- **断电不重置**：剩余时间、锁定状态每 5 秒落盘，拔电源重启后自动恢复锁屏；
- **家长无痕放行**：手机浏览器一键放行 30 分钟/1 小时/2 小时，不在电视上输入任何密码；
- **按单元出题**：题库按「学科 + 单元」组织，只出孩子当前学到的内容。

## 系统组成

```
┌────────────────────┐        ┌──────────────────────────┐
│  Android TV 客户端  │  HTTP  │  家庭服务器（Docker）      │
│  全屏锁屏遮罩       │◄──────►│  · 题库管理网页后台        │
│  前台守护服务       │  ADB   │  · 单元/学科筛选配置       │
│  断电状态持久化     │        │  · 手机远程放行            │
│  无障碍防逃逸       │        │  · 分类打印 / 存 PDF       │
└────────────────────┘        └──────────────────────────┘
```

- **`tv-app/`**：Android TV 客户端（纯原生 Java，零第三方依赖，Android 8+）；
- **`server/`**：FastAPI + SQLite 题库后台（家长网页端 + 电视统一 JSON 接口）。

## 快速开始

见 [docs/DEPLOY.github.md](docs/DEPLOY.github.md)。题库 JSON 格式见
[docs/QUESTION_BANK_FORMAT.md](docs/QUESTION_BANK_FORMAT.md)。

仓库自带少量**原创示例题**演示格式；正式使用请导入自己的题库（支持按学科+单元标注）。
`server/app/english_outline_u1u8.json` 为教科版（广州）英语四年级上册 2024 新教材
U1-U8 提纲，可作为英语出题基准。
